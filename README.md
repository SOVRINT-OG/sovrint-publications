# SOVRINT Publications

Public publication lineage, archival pointers, and DOI status records for SOVRINT™ releases.

## Registry

- MASTER_PUBLICATION_LINEAGE_v1.yaml — publication IDs, release stages, and rights metadata.
- ZENODO_DOI_REGISTRY.yaml — recorded identifiers, staged releases, and verification status.
- archives/SOVRINT_Resonance_Archive_v1.0_README.md — archive scope, boundaries, and checksum.
- Archive checksum: archives/SOVRINT_Resonance_Archive_v1.0.zip.sha256.

## DOI status

The Research Validation Layer DOI is present in first-party GitHub records but was not independently verified against a Zenodo landing page during the latest audit. Other packages in the registry are staged or prepared and do not claim a deposited DOI. Do not treat a staged package as a Zenodo publication.

## Citation

Cite the specific work, author, version/date, repository, and assigned DOI where available. Research citation is required; citation does not grant reuse rights. See SOVRINT_LICENSE.md.
